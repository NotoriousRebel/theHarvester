# Triage labels

These labels belong to `NotoriousRebel/theHarvester`.

| Canonical role | Fork label | Completion state |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue |
| `needs-info` | `needs-info` | Work is waiting for information |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified for an autonomous agent |
| `ready-for-human` | `ready-for-human` | The issue requires human judgment or implementation |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill names a canonical role, apply the corresponding fork label exactly.
